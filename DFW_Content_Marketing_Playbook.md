# DFW Personal Injury Law Firm Content Marketing Playbook

## Executive Summary

This playbook provides a comprehensive content marketing strategy for a personal injury law firm targeting the Dallas-Fort Worth metropolitan area. It includes detailed content pillars, templates, production workflows, and a 90-day content calendar designed to establish topical authority, generate organic traffic, and convert visitors into qualified leads.

#### Video SEO Optimization Checklist

**YouTube Optimization:**
```
□ Title: Include primary keyword + location (under 60 characters)
  Example: "What to Do After a Car Accident in Dallas | Free Legal Tips"

□ Description (First 150 characters):
  Include primary keyword, location, and call-to-action

□ Full Description (1000+ characters):
  - Summary of video content
  - Timestamps for key sections
  - Links to related content on website
  - Contact information and CTA
  - Relevant hashtags (3-5)

□ Tags (500 character limit):
  - Primary keyword variations
  - Location modifiers
  - Related topic tags
  - Brand name

□ Thumbnail:
  - Custom thumbnail (1280x720)
  - Text overlay with key message
  - Attorney face when possible
  - Consistent branding

□ Cards & End Screens:
  - Link to related videos
  - Subscribe prompt
  - Link to website (if eligible)

□ Closed Captions:
  - Upload accurate SRT file
  - Include keywords naturally
```

**Website Video Embedding:**
```
□ Use schema markup (VideoObject)
□ Include video transcript below player
□ Optimize page around video topic keyword
□ Add video to relevant XML sitemap
□ Use lazy loading for performance
□ Include video thumbnail for social sharing
```

### 2.2 Topic Prioritization Framework

#### Priority Scoring Matrix

Each topic is scored on four factors (1-5 scale each):

| Factor | Weight | Description |
|--------|--------|-------------|
| Search Volume | 30% | Monthly search volume for target keyword |
| Business Value | 30% | Likelihood to generate qualified leads |
| Competition | 25% | Difficulty to rank (inverse of KD) |
| Content Gap | 15% | Lack of quality content from competitors |

**Priority Calculation:**
```
Priority Score = (Volume Score × 0.30) + (Business Value × 0.30) +
                 (Competition Score × 0.25) + (Content Gap × 0.15)
```

**Priority Tiers:**
- **P1 (Score 4.0-5.0):** Publish within first 30 days
- **P2 (Score 3.0-3.9):** Publish within 60 days
- **P3 (Score 2.0-2.9):** Publish within 90 days
- **P4 (Score 1.0-1.9):** Backlog for future quarters
