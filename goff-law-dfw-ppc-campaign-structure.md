## Conversion Tracking Setup

### Conversion Actions

| Action | Value | Method |
|--------|-------|--------|
| Phone Call (30+ sec) | $400 | CallRail integration |
| Form Submission | $300 | GTM form tracking |
| Click-to-Call (Mobile) | $150 | GTM event |
| Live Chat Start | $100 | Chat platform integration |

### Call Tracking Setup (CallRail)

1. Create tracking pool (10+ numbers)
2. Enable Dynamic Number Insertion (DNI)
3. Set whisper message: "Google Ads call"
4. Enable call recording (with consent)
5. Set conversion threshold: 30 seconds
6. Configure Google Ads integration

### Enhanced Conversions
- Enable enhanced conversions in Google Ads
- Pass hashed email/phone to Google
- Improves attribution accuracy
