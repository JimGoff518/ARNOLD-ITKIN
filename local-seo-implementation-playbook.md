### 2.2 NAP Consistency Requirements

#### Master NAP Format

Establish ONE canonical format and use it everywhere:

```
PRIMARY NAP:
Business Name: Arnold & Itkin LLP
Address: 8144 Walnut Hill Lane, Suite 1190
City, State ZIP: Dallas, TX 75231
Phone: (214) 555-1234

ACCEPTABLE VARIATIONS:
Street: "Ste." OR "Suite" OR "#" - Pick ONE
Phone: "(214) 555-1234" OR "214-555-1234" OR "214.555.1234" - Pick ONE
State: "TX" OR "Texas" - Pick ONE (TX preferred)
```

#### NAP Consistency Audit Checklist

| Element | Check | Notes |
|---------|-------|-------|
| Business name spelling | ☐ | Exactly matches everywhere |
| LLP/LLC/PC designation | ☐ | Consistent use or omission |
| Street number | ☐ | No variations |
| Street name spelling | ☐ | "Lane" vs "Ln" - pick one |
| Suite format | ☐ | "Suite 1190" vs "Ste. 1190" vs "#1190" |
| City name | ☐ | "Dallas" not "Dallas City" |
| State format | ☐ | "TX" consistently |
| ZIP code | ☐ | 5-digit vs 9-digit - be consistent |
| Phone format | ☐ | Parentheses, dashes, periods |
| Phone number | ☐ | Same number everywhere |

#### Common NAP Errors to Fix

```
WRONG:
- "Arnold and Itkin" vs "Arnold & Itkin"
- "8144 Walnut Hill Ln" vs "8144 Walnut Hill Lane"
- "Ste 1190" vs "Suite 1190" vs "#1190"
- "(214) 555-1234" vs "214-555-1234"
- "Dallas, Texas" vs "Dallas, TX"

RIGHT (Pick one format):
- Arnold & Itkin LLP
- 8144 Walnut Hill Lane, Suite 1190
- Dallas, TX 75231
- (214) 555-1234
```
