
# HIGH-VALUE PRACTICE AREA LITIGATION TACTICS

## 1. Traumatic Brain Injury (TBI) Cases

### Case Value Factors

| TBI Severity | Settlement Range | Key Factors |
|--------------|-----------------|-------------|
| Mild (concussion) | $50,000 - $200,000 | Duration of symptoms |
| Moderate | $200,000 - $1,000,000 | Cognitive impairment |
| Severe | $1,000,000 - $10,000,000+ | Life care needs |
| Permanent disability | $5,000,000 - $25,000,000+ | Lost earning capacity |

### Essential Expert Witnesses

| Expert Type | Purpose | Typical Cost |
|-------------|---------|--------------|
| Neurologist | Diagnosis, prognosis | $500-$1,000/hour |
| Neuropsychologist | Cognitive testing | $400-$800/hour |
| Neuroradiologist | Imaging interpretation | $500-$1,000/hour |
| Life Care Planner | Future needs assessment | $300-$600/hour |
| Vocational Expert | Lost earning capacity | $250-$500/hour |
| Economist | Economic damages | $300-$500/hour |

### Case Development Checklist

**Immediate (48-72 hours):**
- [ ] Photograph scene, vehicles, damage
- [ ] File evidence preservation letter
- [ ] Secure witness statements
- [ ] Request 911 dispatch records

**Medical Documentation:**
- [ ] Hospital admission records
- [ ] Glasgow Coma Scale scores
- [ ] CT scans, MRI imaging
- [ ] Neuropsychological test results
- [ ] All specialist reports

**Ongoing:**
- [ ] Plaintiff symptom diary
- [ ] Family behavioral change statements
- [ ] Employment performance documentation
- [ ] Life care plan development

### Common Defense Tactics & Counters

| Defense Tactic | Counter Strategy |
|----------------|------------------|
| "Mild TBI, full recovery expected" | Neuropsychological testing showing deficits |
| "Pre-existing condition" | Baseline testing, before/after comparison |
| "Malingering" | Validated testing instruments, objective imaging |
| "Symptoms inconsistent" | Daily symptom diary, family testimony |

- [ ] Sudden behavioral changes

- [ ] Bedsores (pressure ulcers)
- [ ] Dehydration or malnutrition
- [ ] Poor hygiene
- [ ] Unattended medical needs

- [ ] Weight loss

6. **Family communication logs** - Complaints, concerns
